# Vocalia — MVP

Aplicación web mobile-first para aprender canto con una experiencia gamificada inspirada en la lógica de las apps de aprendizaje.

## Incluye

- Inicio y progreso
- Ruta de aprendizaje
- Sesiones de ejercicios
- XP y niveles
- Racha
- Reserva de racha
- Misiones diarias
- Logros
- Persistencia con localStorage
- Diseño responsive
- Arquitectura separada HTML/CSS/JS

## Ejecutar

No requiere instalación.

1. Descomprime el proyecto.
2. Abre `index.html` en un navegador moderno.

Para el siguiente sprint se recomienda servirlo mediante un servidor local para facilitar el trabajo con módulos ES:

`python -m http.server 8000`

Luego abrir:

`http://localhost:8000`
